# Failure modes

## Contents

- False-success indicators
- Evidence-loss indicators
- Packaging indicators

## False-success indicators

Block or fail if a concrete stage catches an error then reports completion, a mock enters production, requested frame time is used as measured time, semantic filler replaces pending review, repeated same-model passes are called independent, automatic success becomes fully verified, or verified text merely copies automatic output.

## Evidence-loss indicators

Fail if candidates are concatenated, selective ASR ignores bounds, chunk offsets are local, fixed screenshot limits truncate important events, perceptual dedup removes small changes, crops lack context, metadata exists only in sidecars, image pixels change during metadata updates, new observations overwrite history, disputed claims disappear, metadata facts remain absent from Markdown, or hostile evidence injects markup. Treat missing CUDA/cuBLAS for Whisper as a runtime diagnostic with a CPU/int8 retry, not as permission to silently select a weaker recognizer. When a run rebuilds visual state, rotate stale packets and images out of canonical paths; otherwise old packet spans and orphan images can block an otherwise valid retry. Treat MOSS GPU out-of-memory as an isolated corroborator degradation and preserve the selected ASR candidate.

## Packaging indicators

Fail if the public CLI/module diverge, installed resources are missing, tests import another checkout, mandatory tests skip or assert constants, generated-video tests never decode video, multiple Markdown documents appear, HTML is emitted, or the installed wheel cannot run outside the repository.
