# Support

Use the repository issue forms for reproducible bugs, feature requests, and
usage questions. Include the exact command, operating system, Python version,
package version, and sanitized output from `fast-video-analyzer doctor
--offline` where relevant.

Please do not publish credentials, private media, model weights, complete
generated project directories, or sensitive transcripts/screenshots. Report
security vulnerabilities privately through the process in [SECURITY.md](SECURITY.md).

Support is best-effort and currently covers the latest `main` commit and the
newest tagged release. Questions about unsupported third-party model providers,
host-agent configuration, or platform-specific dependencies may require a
minimal reproducible example before investigation.
